# FitTrack - Fitness Tracker App

A modern fitness tracking app built with Flutter featuring a sleek dark theme with gradient UI elements. Track your workouts, monitor daily goals, and visualize your weekly progress.

## Features

- **Workout Logging** - Log exercises with duration, calories burned, and steps
- **Dashboard** - View today's stats at a glance with gradient stat cards
- **Weekly Chart** - Visualize your calorie burn over the past 7 days
- **Daily Goals** - Track progress towards calorie, steps, and duration goals
- **Exercise Types** - Choose from Running, Walking, Cycling, Swimming, Weight Training, Yoga, HIIT, Jump Rope, Stretching, or add custom exercises
- **Edit & Delete** - Manage your logged workouts easily
- **SQLite Storage** - All data stored locally on your device
- **Dark Theme** - Premium dark UI with purple/blue gradient accents


## Tech Stack

- **Framework:** Flutter 3.47.5
- **Language:** Dart
- **Database:** SQLite (sqflite)
- **Charts:** fl_chart
- **State Management:** setState
- **Design:** Material Design 3 (Material You)

## Dependencies

- `sqflite` - Local SQLite database
- `path` - File path handling
- `fl_chart` - Bar chart visualization
- `intl` - Date formatting

## Installation

1. Clone the repository
```bash
git clone https://github.com/Syed-Khizer-Rizvi/CodeAlpha_Fitness_Tracker_App.git
```

2. Navigate to project directory
```bash
cd CodeAlpha_Fitness_Tracker_App
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```
